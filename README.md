# تقنية تنصت.. وأمل يتجدد

كلية الحاسبات وتقنية المعلومات — جامعة الطائف  
تحت إشراف المكتب التنفيذي لمكافحة المخدرات بجامعة الطائف

تجربة توعوية عربية RTL مبنية بـ HTML وCSS وJavaScript، بلا خادم تطبيقات أو قاعدة بيانات أو حسابات أو خدمات ذكاء اصطناعي. الرابط الحالي: https://hope-listens-taif.vercel.app/

## التشغيل والتحقق

يتطلب Node.js حديثًا (22 أو أحدث).

```sh
npm ci
npm start
```

افتح `http://127.0.0.1:4173/`. الجدار `/wall/` والإدارة `/admin/`. لا تفتح HTML مباشرة عبر `file://` لأن وحدات JavaScript تحتاج خادمًا.

```sh
npm test
npm run build
```

المشروع ثابت؛ `build` يتحقق من صياغة JavaScript والهوية والمسارات والأصول وRTL وهدف QR، ولا يحتاج ترجمة أو تجميع. لا يوجد TypeScript أو إعداد Lint منفصل. مكتبات الاختبار وتوليد QR تطويرية ولا تُحمّل للزوار.

## الأقسام

1. جرب قرارك: خمسة مواقف، ثلاثة خيارات، مؤشرات رمزية، آثار تعليمية، بطاقة تعلم PNG.
2. رفيق الأمل: ردود محلية جاهزة، اقتراحات، مسح المحادثة، وتوجيه للمختص عند الحاجة.
3. اكشف الحقيقة: عشر معلومات، حقيقة أو خرافة، شرح ومصدر رسمي، نتيجة ومراجعة.
4. جدار الأمل: رسالة مجهولة حتى 150 حرفًا، فلترة أولية، انتظار مراجعة، وبطاقة شخصية.
5. كن السند: خمس حكايات لتعلم الإنصات وحدود الدعم وطلب المختص.
6. وعد لنفسي: نص مقترح أو خاص، ثلاثة تصاميم وثلاثة ألوان، تاريخ اختياري، PNG ومشاركة الجهاز.
7. المساعدة: 937 للتوجيه الصحي و995 للبلاغات الأمنية، مع مصادر رسمية؛ تبقى المساعدة متاحة من كل صفحة.

## إدارة البوث

افتح `/admin/` في المتصفح الذي يحفظ رسائل البوث. أقر بأن الإدارة محلية ثم اضغط «فتح وضع المشرف». هذا حاجز استخدام لمنع التعديل غير المقصود، وليس مصادقة أو حماية؛ أي مستخدم للجهاز يستطيع فتحه. لا كلمة مرور مضمنة ولا أسرار.

الرسائل الجديدة بحالة انتظار، ولا تظهر للزوار. اضغط «موافقة» لإظهارها أو «رفض» لإخفائها. الحذف يتطلب تأكيدًا. تعرض الإدارة العدد حسب الحالة، وتتيح تصدير الرسائل المعتمدة إلى JSON. عند الاستيراد افحص المصدر: الرسائل المستوردة المعتمدة ستظهر فورًا بعد التأكيد؛ يُتحقق من الملف كاملًا قبل الدمج وتُتجاهل المعرفات المكررة. إعادة الضبط تتطلب كتابة «حذف». يقفل وضع المشرف بعد 60 ثانية من الخمول.

الرسائل الافتتاحية موسومة بأنها من فريق المشروع، وهي محتوى تحريري وليست إحصاءات أو رسائل زوار. لا تُحذف مع بيانات المتصفح.

## حدود التخزين والخصوصية

- الرسائل داخل LocalStorage تحت `hope-wall-v1`؛ حد 500 رسالة و1 ميغابايت لملف الاستيراد.
- لا مزامنة بين الأجهزة أو المتصفحات أو ملفات المستخدم المختلفة أو الروابط المختلفة. نفس الجهاز وحده لا يكفي: يجب استخدام المتصفح والأصل نفسه.
- يحدّث `/wall/` الرسائل عند تغيير التخزين في تبويب آخر على الأصل نفسه. تستخدم العمليات Web Locks عندما يدعمها المتصفح؛ في المتصفحات القديمة تجنب تعديل الرسائل في تبويبي إدارة متزامنين.
- محو بيانات الموقع أو المتصفح قد يفقد الرسائل. صدّر نسخة معتمدة قبل الفعالية وبعدها.
- محادثة المساعد والقرارات والوعد في الذاكرة فقط. لا تحليلات أو طلب بيانات صحية أو شخصية.
- الفلتر بسيط وقد يرفض نصوصًا سليمة أو يفوّت إساءة؛ مراجعة المشرف أساسية. لا ترسل بيانات شخصية.
- مشاركة البطاقة عبر النظام اختيار صريح من الزائر؛ التطبيق نفسه لا يرفع نصها لخادم.

## جلسة الزائر ووضع الكشك

«رحلة جديدة» يمسح القرارات والمحادثة ومسودات الرسائل والبطاقات، مع الاحتفاظ بالجدار. «وضع الكشك» يطلب ملء الشاشة ويعيد الجلسة بعد 60 ثانية من الخمول. إن منع المتصفح ملء الشاشة يبقى مؤقت الكشك فعالًا. يظل التكبير متاحًا للوصول، وتُقلل إيماءات اللمس العرضية. احترم وضع تقليل الحركة في النظام.

## تعديل المحتوى

| الملف | المحتوى |
|---|---|
| `dist/js/config.js` | الهوية، الجهات الرسمية، النصوص المشتركة، الردود، الفلتر، رسائل البداية |
| `dist/js/content/decisions.js` | مواقف جرب قرارك؛ الخيارات وbest والآثار والمهارة |
| `dist/js/content/truth.js` | أسئلة الحقيقة وإجاباتها ومصادرها |
| `dist/js/content/ally.js` | حكايات كن السند |
| `dist/js/content/promises.js` | الوعود وألوان وتصاميم البطاقات |
| `dist/js/app.js` | قوالب الواجهة وتسميات الإجراءات |
| `dist/styles.css` | التصميم والاستجابة والوضع الداكن |
| `dist/js/learning-card.js` | رسم البطاقات بخط عربي محلي |

المحتوى التعليمي ليس تشخيصًا أو تنبؤًا. راجع المصادر الصحية عند تعديله. الخطوط المرفقة محفوظة دون تغيير في `dist/assets/fonts/` وتُحمّل عبر `@font-face`. لا صور أو خطوط خارجية ولا شعارات رسمية مضافة.

## QR والنشر

رمز QR الحالي يفتح رابط Vercel العام. لتحديثه عند تغيير الرابط فقط:

```sh
node scripts/qr.mjs https://hope-listens-taif.vercel.app/
```

لا يلزم أي متغير بيئة. لا تضف مفاتيح API أو Firebase. تعليمات تحديث **مشروع Vercel الحالي** في [VERCEL.md](VERCEL.md). لم يُنفّذ نشر ضمن هذا التعديل. نتائج الاختبار وحدود التحقق في [TESTING.md](TESTING.md).
